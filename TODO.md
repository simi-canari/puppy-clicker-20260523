# Testing checklist

Repeat on Windows, Android Chrome and iPhone Safari, in the browser and installed PWA.

- [x] Audio works after backgrounding, locking and reopening, at the saved volume.
- [x] Offline reopening retains the image, both sounds, slider and saved preferences.
- [x] Update prompt waits for acceptance; reload preserves settings and a second tab stays open.

Browser data clearing/private browsing can remove saved settings. App volume is relative
to device volume; it does not change the device volume setting.
